# 性能测试

项目提供一个仅依赖 JDK 21 的只读 HTTP 基准工具，避免把不可复现的性能数字写进简历。

先启动应用，再在项目根目录执行：

```powershell
java scripts/performance/HotelApiLoadTest.java http://127.0.0.1:8080 "/api/room/list?page=1&size=10" 500 20 1000
```

参数依次为：服务地址、接口、请求总数、并发数、P95 上限（毫秒）。脚本预热后输出成功率、吞吐量、P50、P95、P99 和最大响应时间；出现非 2xx 响应或 P95 超过阈值时返回非零退出码。

测试登录接口时不要提交真实账号。测试受保护的只读接口，可临时设置 `HOTEL_AUTH_TOKEN` 环境变量；不要把令牌提交到 Git。

性能结果受机器、数据库数据量和后台进程影响。简历中只记录注明环境且能够重复测得的数据。

## 当前基线（2026-08-29）

- 环境：Windows 本机，JDK 21.0.9，应用与 MySQL 均运行在本机
- 场景：客房列表只读接口，500 次请求，并发 20
- 结果：成功率 100%，吞吐量 168.45 req/s，P50 90 ms，P95 251 ms，P99 566 ms

该结果是开发机基线，不等同于生产容量。更换机器、数据量或代码后应重新执行并更新记录。
